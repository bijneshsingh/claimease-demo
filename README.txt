ClaimEase – concept demo (mobile web app)
=========================================
Product design case study by Bijnesh Singh. All data is sample data; nothing is sent anywhere.

Files: index.html, styles.css, app.js, manifest.webmanifest, sw.js, icons/
No build step needed. Upload the whole folder (with index.html at the top level).

Try it: log in with any 10 digits and any 6-digit code (000000 shows the wrong-code state),
start a claim, tap "Use sample", check documents, fix the 2 items, submit.
Updates arrive a few seconds after you submit. Reset the demo from the Help tab.
